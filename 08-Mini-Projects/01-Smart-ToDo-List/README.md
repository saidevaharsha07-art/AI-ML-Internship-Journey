# 📝 Smart To-Do List Application Using Python

A simple and efficient task management application built using Python. This project helps users organize daily tasks, track progress, and manage priorities through a menu-driven interface.

## 🚀 Features

- ✅ Add Tasks
- 📋 View Tasks
- ✏️ Update Tasks
- 🗑️ Delete Tasks
- ✔️ Mark Tasks as Completed
- 🔍 Search Tasks
- ⭐ Priority Levels (High / Medium / Low)
- 💾 File Storage using `t1.txt`
- ⚠️ Exception Handling
- 🧹 Clear All Tasks
